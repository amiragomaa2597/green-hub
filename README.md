# The Green Hub

MBA Team Final Project — Group 5  
A smart & sustainable community center landing page (Angular).

## Local development

```bash
npm install
npm start
```

Open `http://127.0.0.1:4200/`.

## Production build

```bash
npm run build
```

## GitHub Pages

This repo deploys automatically via GitHub Actions on every push to `main`.

Live site (after first successful deploy):

`https://<your-username>.github.io/green-hub/`
